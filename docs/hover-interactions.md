# Hover and interaction-state audit

Reviewed hover and declared interaction-state rules across all 66 application CSS files, including CSS modules,
shared styles, pseudo-elements, grouped focus/selected states, and accessibility overrides.
Hover rules appear in 19 stylesheets; the expanded inventory also includes native range focus and font-dialog open rules. Runtime font-preview hover callbacks were also inspected;
they prepare font previews and remain unchanged.

## Decisions

- Add missing transitions on the owning base selector, so both hover entry and exit are smooth.
  Shared control feedback uses the 200ms role; real pointer/touch presses use the 160ms role.
  The deliberate 360ms marketing-carousel movement remains an explicit exception.
- Transition only the changing color, background-color, border-color, opacity, and existing transform
  properties. Retain each component's original colors, layout, selected states, and disabled states.
- Shadows, gradients/background images, text decoration, visibility switches, native controls, and
  focus outlines remain immediate. No `transition: all`, ambient movement, motion library, or layout
  animation is introduced by this audit.
- Existing hover movement requires `(hover: hover) and (pointer: fine)`. Keyboard focus keeps the
  visible color/border/focus-ring treatment without moving content. Reduced-motion overrides retain
  baseline positioning/rotation and suppress movement, rather than merely removing its duration.
- Preserve the Maker Editorial landing, Reference public pages, and Workshop editor systems.
  Static captures and browser feel checks follow visual approval; static source review is not
  evidence of perceived smoothness or device frame performance.

## State decisions

| State                                    | Treatment                                                                                                                                                                                                                             |
| ---------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Hover and release                        | Base-selector transitions cover colors/borders/backgrounds and existing bounded transforms; movement requires hover/fine-pointer support.                                                                                             |
| Active / pressed                         | 160ms feedback confirms real mouse/touch presses. Public press movement is input-modality gated; keyboard activation stays still.                                                                                                     |
| Focus / focus-visible / focus-within     | Rings/outlines/shadows remain immediate. Companion color feedback uses existing control roles; focus does not move content. Native range focus stays native and immediate.                                                            |
| Selected / checked / current             | Colors/borders and existing checkmark opacity may transition; the native value/ARIA selection updates immediately. Custom radio/checkbox fills and keyring marker colors now have matching transitions.                               |
| Expanded / open                          | Existing language chevron inherits its transform transition. The surface-menu chevron now rotates over 200ms for pointer input, instantly for keyboard/reduced motion. Native details content and plus/minus glyphs remain immediate. |
| Disabled / loading / busy                | Availability, cursor, text, and disabled opacity update immediately. Existing progress spinners retain their reduced-motion handling. No delay is added to accepting input or reporting completion.                                   |
| Error / warning / success / print status | Messages and severity styling remain immediate; no fading or entrance delays obscure recovery or print safety.                                                                                                                        |
| Setup progress                           | Color/border feedback remains; width changes are immediate instead of animating layout.                                                                                                                                               |
| Visited / native / responsive            | Preserve existing browser/native behavior and responsive layout. Do not animate text decoration, visibility, DOM removal, or layout to force every state to move.                                                                     |

## Changes by surface

| Surface                                          | Changes / retained behavior                                                                                                                      |
| ------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| Shared header, account, language, consent        | Fill missing color/border/background transitions; shared icon motion remains action-specific.                                                    |
| Landing                                          | Fill GitHub-link and carousel-arrow feedback; retain other transition timings, gate movement, keep focus still, snap shadows.                    |
| Public guides/templates/resource links           | Add resource-link color transition; preserve card/CTA feedback with gated movement and correct reduced-motion baseline.                          |
| Profile                                          | Retain existing feedback; gate hover lift and suppress movement under reduced motion.                                                            |
| Customizer controls and font browser             | Fill filter/provider/manual-copy and font-about color gaps; existing choices, resets, inputs and font preview state keep their own transitions.  |
| Hardware and color choices                       | Add border/background feedback to opening cards and color-swatch borders; preserve native color inputs and radio behavior.                       |
| Preview toolbar, appearance and surface controls | Retain prior toolbar/Photo transitions; fill appearance-button transitions and surface-option text color.                                        |
| Setup and export                                 | Keep existing states; use control timing for setup colors, fill export recovery transitions, and gate recovery-button hover movement.            |
| Template/style rails                             | Preserve visible-state opacity/transform behavior; add the color/background/border properties shadowed by the rail's own transition declaration. |
