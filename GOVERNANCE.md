# Governance

## Current model

Open Keychain is currently maintained by WilfredoN. The maintainer is responsible for releases, security response, roadmap prioritization, and final decisions when consensus cannot be reached.

## Contributions

Changes should be proposed through pull requests and follow [CONTRIBUTING.md](CONTRIBUTING.md). Small fixes may be merged directly by the maintainer; substantive changes should include tests and documentation where applicable.

The maintainer may request review from contributors with relevant geometry, frontend, infrastructure, or security experience. Review is advisory until additional maintainers are formally listed.

## Decision process

Decisions are made from the project goals, user impact, printable-geometry safety, privacy, maintainability, and compatibility with the MIT license. The roadmap is directional rather than a promise, and security or correctness issues take priority over feature work.

Future maintainers and reviewers will be added through documented project contributions and explicit agreement from the current maintainer.
