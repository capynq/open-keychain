# Support

Open Keychain is primarily a browser application. The default build generates geometry locally and does not require an account or hosted service.

## Before asking for help

1. Check the [README](README.md), [roadmap](ROADMAP.md), and [contributing guide](CONTRIBUTING.md).
2. Reproduce the issue with the latest `main` build and record the text, template, font, browser, operating system, and viewport.
3. For self-hosting problems, include the deployment mode, relevant Docker Compose service, and a redacted configuration excerpt.

## Where to ask

- Use the [bug report form](https://github.com/WilfredoN/open-keychain/issues/new?template=bug_report.yml) for reproducible defects.
- Use the [feature request form](https://github.com/WilfredoN/open-keychain/issues/new?template=feature_request.yml) for product ideas.
- Use [GitHub Discussions](https://github.com/WilfredoN/open-keychain/discussions) for questions and design conversations when Discussions are enabled.
- Follow [SECURITY.md](.github/SECURITY.md) for vulnerabilities. Do not disclose security issues in public issues.

There is no guaranteed response time. Hosted-service accounts, quotas, billing, and deployments are experimental until the roadmap says otherwise.
